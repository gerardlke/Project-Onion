# CS1101S: Programming Methodology

Recursion is a programming technique where a function calls itself with a smaller input until a base case is reached, unwinding the call stack on return.

The Base Case terminates recursion by returning a result directly without further recursive calls, preventing infinite loops and stack overflow errors.

Higher-Order Functions accept other functions as arguments or return them as results, enabling abstraction over computation patterns like map, filter, and reduce.

Pure Functions always produce the same output for the same input and have no side effects, making programs easier to reason about and test.

Tail Recursion places the recursive call as the final operation, allowing compilers to optimise it into an iterative loop and eliminate stack overflow risk.

Substitution Model explains how expressions are evaluated by replacing function calls with their bodies and substituting argument values for parameters.

Scope determines where a variable is accessible in a program, with lexical scoping meaning a function's variable lookup is determined by where it is defined, not where it is called.
